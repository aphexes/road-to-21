# Road to 21.1

A 15-week training tracker: 2 November 2026 to a solo half marathon on 14 February 2027.

Open it at **https://aphexes.github.io/road-to-21/**, then on iPhone tap Share → Add to Home Screen to run it full-screen like an app. It works offline after the first visit.

Progress (ticks, moved days, weigh-ins) is stored only in the browser on your device and is never uploaded. Use Plan → "Back up to a file" to move it between devices.
